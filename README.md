# Network Automation Tools — NiceGUI

Two independent Python applications for simulated network operations and authorized lab development:

- `Program1_Interface_Tunnel/` — interface status, Shutdown / No Shutdown, simulated transports and Cisco Direct SSH adapter.
- `Program2_Dot1x_Recovery/` — workbook mappings, simulated recovery, snapshot/diff and conflict-aware restore.

See [คู่มือติดตั้งและใช้งานภาษาไทย](docs/README_TH.md), [scope and limitations](docs/SECURITY_AND_LIMITATIONS.md), and [test evidence](docs/TEST_REPORT.md).

The original specification is retained at `CODEX_NICEGUI_MASTER_PROMPT` (the checkout does not contain a `.md` version or `MASTER_SPEC.md`). Live console/jump and real device recovery are intentionally unavailable pending implementation and lab validation. This is not the complete master specification implementation.

See the [dashboard redesign and desktop screenshots](docs/UI_REDESIGN.md).
